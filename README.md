# Chat App : messagerie en temps réel

Application web de messagerie instantanée permettant à deux utilisateurs de discuter en temps réel depuis leur navigateur.

> Projet réalisé à partir d'un tutoriel pour apprendre la communication en temps réel avec Socket.io.

## Stack technique

- Frontend : React, Tailwind CSS
- Backend : Node.js, Express
- Temps réel : Socket.io

## Fonctionnalités

- [x] Envoi et réception de messages en temps réel
- [x] Conversation entre deux utilisateurs

## Installation

```bash
git clone https://github.com/hezouBeke/NOM-DU-REPO.git
cd NOM-DU-REPO
```

**Serveur**
```bash
cd backend
npm install
npm run dev
```

**Client**
```bash
cd frontend
npm install
npm run dev
```

Variables à renseigner dans `server/.env` :

| Variable | Description |
|---|---|
| `PORT` | Port du serveur (ex. 5001) |
